# NupicAI brand assets

Umiesc glowne logo aplikacji w tym katalogu jako `logo.png`.

- zalecany format: przezroczysty PNG lub WebP,
- logo moze byc szerokie; interfejs miesci je w obszarze 196x58 px,
- po podmianie assetu uruchom `npm run build`.

Brak pliku `logo.png` jest obslugiwany: aplikacja pokazuje wtedy ikone audio.
